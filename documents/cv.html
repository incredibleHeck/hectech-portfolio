EduScheduler Pro — Constraint-Solving Timetable Suite

v1.0.0 · delivered
Tauri v2 (Rust), React 18, TypeScript, Web Workers, Ed25519

  • Implemented offline licence activation with Ed25519-signed keys verified against an embedded public key — no account, no server call — alongside automatic restore points with undo/redo.
