v1.0.0 · delivered
Tauri v2, React 18, TypeScript, Web Workers, Ed25519 · one-time purchase, fully offline
  • Modelled academic timetabling as a constraint satisfaction problem over teachers, rooms, class groups and curriculum splits, implementing a hybrid solver — dynamic minimum-remaining-values ordering with backtracking, tabu search to escape local optima, and a repair phase bounded by a time budget — as 11,443 lines of TypeScript in a Web Worker.
  • Placed a real school timetable of 20 classes, 63 teachers and 615 curriculum periods per week in under three minutes, with no unplaced lessons, no curriculum gaps and no hard conflicts — replacing a manual process that had taken the school multiple weeks.
  • Rebuilt clash detection to compare real clock times rather than period indices, so schools running staggered bell schedules across divisions validate correctly.
  • Implemented offline licence activation with Ed25519-signed keys verified against an embedded public key, with no account and no server call, alongside automatic restore points with undo/redo.
